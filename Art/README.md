# Art Projects

This folder contains art and interactive media projects — same structural layer as `Games/` and `Buisnes/`.

## Structure

- `TouchDesigner/` — interactive TouchDesigner learning and art pieces

## Getting Started

Each art project should have its own subfolder with:
- README.md - Project description and setup
- .gitignore - Files to ignore
- .cursorrules - Project-specific Cursor AI rules
- PROGRESS.md - Optional learning / milestone checklists
